Гайд по установке
Вручную

Заполни данные новой локации — панель сгенерирует ключи и команду, включит TCP+Reality, gRPC+Reality и XHTTP+Reality разом. Выполни команду на чистом Ubuntu-сервере (по SSH) — Xray установится и настроится сам, ничего дополнительно передавать не нужно.

Для ноды, которую ты уже настроил(а) сам(а) — просто вставь её параметры Reality.

Редактировать ноду

Смена адреса/ключей/short ID сломает уже выданные ссылки у текущих подписчиков этой ноды — используй только если точно понимаешь, что делаешь.

У локальной ноды (de1) параметры подключения берутся из .env на сервере — здесь можно поменять только отображаемое название.
